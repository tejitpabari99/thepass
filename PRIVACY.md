# Privacy

[Terms](https://github.com/tejitpabari99/thepass/blob/main/TERMS.md)

thepass counts how it is used, anonymously. It sends one count per user, when `start` first sets up.

## What is collected
- Tool type (plugin), plugin name (`thepass`), tool name (`start`)
- Event type (`setup_done`)
- Test-or-real flag
- Plugin version
- Organization or team name as typed (lowercased), or a random anonymous org id if none is given
- Random anonymous code
- Which AI or app sent it (Claude, GPT, Gemini, Grok, Perplexity, other: a category only)
- UTC time of the request

## What is never collected
- IP address
- Raw user-agent text
- Names
- Emails
- Code, repo names, branch names
- File names or contents
